# Tài liệu tham khảo

- [`DAC_TA_HE_THONG.md`](DAC_TA_HE_THONG.md) là đặc tả tổng hợp. Phần **Phạm vi hiện
  hành (v2.0)** ở đầu tài liệu là nguồn phạm vi có hiệu lực; các use case 1.0 bên
  dưới được giữ lại làm tham khảo và backlog.
- [`../CONTENT HUB/KIEN_TRUC_VA_PHAM_VI.md`](../CONTENT%20HUB/KIEN_TRUC_VA_PHAM_VI.md)
  mô tả quyết định kiến trúc và chức năng hiện có.
- [`../CONTENT HUB/KE_HOACH_KHOA_LUAN.md`](../CONTENT%20HUB/KE_HOACH_KHOA_LUAN.md)
  mô tả kế hoạch hoàn thiện, kiểm chứng và bảo vệ.
- [`diagrams/`](diagrams/) chứa sơ đồ quy trình và file nguồn Draw.io.

Khi tài liệu khác nhau, ưu tiên use case nghiệm thu và phạm vi khóa trong
`CONTENT HUB/KE_HOACH_KHOA_LUAN.md`, sau đó là mục phạm vi v2.0 ở đặc tả tổng hợp.
